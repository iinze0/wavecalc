# WaveCalc

> A clean, local-first antenna length and frequency calculator for Sub-GHz, Wi-Fi, and common RF bands.  
> No accounts. No tracking. Just open the HTML.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

---

## What it does

Quickly calculate quarter-wave, half-wave, and full-wave antenna lengths for any frequency, with common preset bands used by Flipper Zero, T-Embed, Bruce, and other Sub-GHz / RF tools.

- Presets for 315 MHz, 433 MHz, 868 MHz, 915 MHz, 2.4 GHz, 5 GHz
- Velocity factor adjustment (default 0.95 for most wire)
- Visual length bars
- Copy results
- Works completely offline

## Use it

Open `index.html` in any browser, or host it on GitHub Pages.

No build step. No dependencies.

## Why

Hardware people keep looking up the same antenna length formulas. This makes it instant and pleasant to use.
